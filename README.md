# GIS 分析助手

面向 GIS 空间分析的自然语言工作台。用户选择研究范围和数据后，可复用 Skill 或规划自定义工作流，检查参数并确认执行，在地图和对话中查看分析成果。

## 主要能力
- 数据目录选择、自然语言定位数据、年份确认与研究范围提取。
- 设施数量、密度、多样性及缓冲区面积覆盖率 Skill。
- 工作流画布审查、参数编辑与自然语言调整。
- 地图预览、图层属性、分析结论和统计图表。
- 按任务保存成果，原始数据按只读资产管理。

## 下载与部署
在 [Releases](https://github.com/sanshui366/gis-analysis-agent-releases/releases) 下载编译部署 ZIP，并核对 SHA256SUMS.txt。
详见 [部署说明](DEPLOYMENT.md) 和 [版本记录](CHANGELOG.md)。

当前为试用版本，使用前应以自有数据进行验收。编译包要求 Windows x64、ArcGIS Pro 3.6 对应的 Python 3.13 环境及有效 ArcGIS 授权；不包含 ArcGIS Pro、Python、第三方依赖、模型服务密钥或实际数据。
